# Gotchas — avenues tried, so they are not tried again

Four lines, sometimes six. Not a report, not a finding, not a rule.

```markdown
### The thing you would reasonably try

What happens instead, in one or two sentences.

**Instead:** what to do, naming the file or the page.
```

An entry that does not end with **Instead:** is a complaint; finish it or
delete it. A gotcha carries no date and no evidence: the measurement that
produced it, if any, lives in the lab book entry it was lifted from.

| Domain | File | For |
| --- | --- | --- |
| the prototype tree | [`prototype.md`](prototype.md) | why the tests fail, what does not import, what the docs promise that the code lacks |

A new domain is a new file, never a new section in this one.
